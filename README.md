Collection of simple Mahjong Soul mods using [mjslib](https://github.com/vg-mjg/mjslib) that don't need a dedicated repository.

Follow installation instructions for it first, then copy mods from this repo to `<GameDir>/BepInEx/plugins`.

## decensor

Neuters the client-side text filter for all the bad words like "tenhou" or "tiananmen".

## weebnames

Replaces the localized yaku names with the Japanese or nyagger ones.

## precise friend times

Shows exact date and time for offline players on your friend and application list.

## friendly uncle

Enables profile inspection button in the log viewer, profile comments and shows the ID on all profiles.

## bond voice

Play all character voices regardless of bond level requirements.
